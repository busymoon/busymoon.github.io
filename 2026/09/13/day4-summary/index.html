Day4 - 学习总结

今日 Agent 学习要点

Q1：什么是 Skill？
A：Agent 中一项可复用的能力，类似软件工程中的 Service / Capability。

Q2：什么是 Prompt？
A：指导 LLM 执行某个认知动作的 Instructions，是 Skill 的组成部分之一。

Q3：Skill 和 Prompt 的关系是什么？
A：Skill ≠ Prompt。一个 Skill 可以包含 Prompt、Context、Taxonomy、Policy、Few-shot、Tool、Output Schema、Eval 等，也可以包含多次 LLM 调用。

Q4：Workflow 和 Skill 的关系是什么？
A：Workflow 负责组织多个 Skill/Tool 完成整体目标；Skill 负责提供具体能力。

Q5：Prompt、Context 的区别是什么？
A：Prompt 决定“怎么做”；Context 决定“这一次做的时候知道什么”。

Q6：Taxonomy 是什么？
A：定义系统中“有哪些概念/答案”。

Q7：Decision Policy 是什么？
A：定义如何根据证据从多个候选答案中做出判断。

Q8：Few-shot 是什么？
A：通过具体案例向模型示范如何应用抽象的 Policy。

Q9：Tool 是什么？
A：Agent 用于获取信息、执行计算、验证结果或改变外部环境的确定性能力。

Q10：什么时候应该用 Tool，而不是 LLM？
A：能够通过确定性计算、查询、验证或转换得到的结果，优先交给 Tool。

Q11：Eval 是什么？
A：衡量 Skill/Agent 是否正确，以及修改后是否真正改善、是否产生 Regression。

Q12：Agent 的核心运行循环是什么？
A：Observe → Decide → Act → Observe，直到 Goal 完成或终止。

Q13：Observe 是什么？
A：Agent 获取当前环境、任务和工具执行结果等信息。

Q14：Decide 是什么？
A：根据 Goal、State、Context、Policy 和 Available Actions 决定下一步行动。

Q15：Act 是什么？
A：调用 Tool、Skill、Human 等执行 Decision，产生新的 Observation。

Q16：为什么同一个错误结果可能有不同原因？
A：可能是 Observe 信息缺失、Decide 判断错误，也可能是 Act 执行错误，需要 Failure Decomposition。

Q17：什么是 State？
A：描述当前任务“现在做到哪里、处于什么状态”。

Q18：什么是 Context？
A：为了当前这一次 Decision，选择让模型看到的信息。

Q19：什么是 Memory？
A：从过去经历中保留下来、未来任务可能再次使用的信息。

Q20：什么是 History？
A：记录过去发生过什么；History 是“怎么走到这里”，State 是“现在在哪里”。

Q21：Memory 和 Knowledge 有什么区别？
A：Memory 主要来自历史运行和交互经验；Knowledge 是相对稳定、权威、经过治理的外部知识。

Q22：Memory 是否一定要变成 Knowledge？
A：不一定。只有经过审核、治理后，部分 Memory 才可能沉淀为正式 Knowledge。

Q23：Memory 如何影响未来 Decision？
A：Memory → Retrieval → Context → LLM → Decision。

Q24：Memory 系统最核心的两个问题是什么？
A：什么时候记（Memory Write Policy）和什么时候想起来（Memory Retrieval Policy）。

Q25：State、Context、Memory 最简单的记忆方式是什么？
A：State = Where am I?；Context = What do I need to know now?；Memory = What from the past should I remember?

Q26：Context 的信息可以来自哪里？
A：State、Observation、History、Memory、Knowledge、Tool Results、用户输入等。

Q27：Context Engineering 的核心是什么？
A：为当前 Goal + State + Decision 选择最合适的信息，而不是简单把所有信息塞给 LLM。

Q28：Agent 架构设计中的重要原则是什么？
A：结果错误时不要默认“改 Prompt”，先定位错误属于 Prompt、Context、Taxonomy、Policy、Few-shot、Tool、Workflow、State/Memory 还是其他层。
