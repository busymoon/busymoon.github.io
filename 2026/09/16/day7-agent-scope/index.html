10. 到这里，我们可以升级之前的 Agent 定义

Agent 是能够 Reasoning + Tool Calling 的 LLM。

现在应该升级成：

Agent 是一个以 State 为核心，由 Runtime 驱动，通过 Context 将当前世界状态交给 LLM 做 Decision，再通过 Policy 控制 Action、Tool 改变状态，并不断进行 State Transition 的运行系统。
