Day4 - Agent 的 8 个层次

对，你现在问到了一个比“怎么写 Decision Rule”更根本的问题：Agent 中这些东西到底分别负责什么，以及它们之间是什么关系。

而且你对 batch_id 的判断方向基本对，但我会修正一点：“用于过滤”本身不能很好地区分 DATE 和 IDENTIFIER。ID 同样经常用于过滤。更关键的是“这个字段在业务中代表什么”，以及操作是否体现这种语义。

先把整体模型建立起来。

一、先纠正一个概念：Skill 不等于 Prompt

前面为了教学我把它简化了。更准确地说：

Prompt 是 Skill 的一个组成部分，而不是 Skill 本身。

二、8 个概念到底分别解决什么问题？

可以用一句话分别记住。

概念 它回答的问题
Prompt 我要模型现在做什么？
Context 模型这一次做判断时知道什么？
Taxonomy 有哪些合法的概念/类别？
Decision Policy 根据已有信息，应该怎么做决定？
Few-shot 给模型看几个“应该怎么判断”的示范
Tool 哪些事情不要让 LLM 猜，而是实际计算/执行？
Workflow 先做什么、后做什么、什么时候调用谁？
Eval 整套东西到底做得好不好？修改后有没有变差？

这八个概念看起来很像，但职责其实非常不同。
